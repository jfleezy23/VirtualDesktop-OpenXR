# Bounded NR color transfer — 2026.11.08.1

This release adds **bounded perceptual color transfer** to reduced-processing NR and retains
**OFXR 2×/3×/4×**, frame-delivery recovery and automatic game profiles. Your saved NR, FG,
coverage and appearance settings stay in place.

## What changes

With NR enabled and processing below 100%, the existing reconstruction step transfers the model's
lightness and color edits through a perceptual color space. The bounded transfer limits how those
edits carry across differences between the guide and the native image. It adds no model evaluation,
image copy or rendering pass.

Use the existing **NR processing resolution (%)** control, for example 80% or 85%. There is no new
toggle. **Native 100% processing is unchanged.** Coverage remains independent, including 100%,
and existing appearance controls retain their meaning.

The existing edge weights and sharpening behavior remain unchanged. The FG module and NR model
are unchanged.
4× keeps its recovery for missed generated slots, using later useful images when available and
real frames as fallback. No FPS increase or headset-latency improvement is claimed for the color update.

Controls also exposes **Requested reconstruction mode** for Globals and game profiles: Standard,
Depth assist, or experimental Depth reconstruction. See the [mode guide](../DEPTH-MODES.md) for
depth/backend requirements and fallback behavior. Close and relaunch the game after changing it;
the selector records a request rather than proof that a depth mode is active.

## Install or upgrade

Download the matching runtime and Controls ZIPs from the
[release](https://github.com/jfleezy23/VirtualDesktop-OpenXR/releases/tag/nr-fg-2026.11.08.1)
and verify `SHA256SUMS-2026.11.08.1.txt`. Follow the
[quickstart](../NR-FG-QUICKSTART.md) and [side-by-side upgrade guide](../SIDE-BY-SIDE-RUNTIME.md).
Close games before replacing the matching host, FG module and `CUSTOM-RUNTIME.json`.
Keep Streamer's original files and your separately licensed NR component in place.

Select **Custom VDXR** in Controls and **VDXR** in Streamer for the next game launch.
Turn Virtual Desktop's **SSW Off** when using OFXR. Saved game profiles continue to override Globals;
keep the settings that already work for you. The existing Controls images and layout still apply.
See the [Controls guide](../NR-FG-CONTROLS.md) and [Steam/Oculus routing guide](../GAME-COMPATIBILITY.md).

**No proprietary NR DLL or neural model is included or downloaded.** FG with NR off does not
require the NR component. Appearance and interpolation results still depend on the game and scene;
this release does not establish universal compatibility or artifact-free motion.
