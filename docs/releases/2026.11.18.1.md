# NR/FG 2026.11.18.1

## Frame delivery when NR runs late

Eligible **OFXR 2×, 3× and 4×** sessions can present the last completed stereo frame while the current NR frame is
pending. The repeat uses the original render pose and paired depth when present. The runtime resumes with the
fresh real frame when it is ready and keeps the 4× rule for skipping expired, unopened presentation slots.

Stereo replay requires independent presentation, a valid frame reservation and a compatible completed frame.
It covers the current reservation. A longer GPU stall can still delay the next group while outstanding work
retires. Ordinary FG with NR off continues to use its existing presentation path.

## Synchronization and recovery

- Drain a failed NR submission before the next frame resolves into its source textures. This applies to
  native and reduced-resolution NR, including a retry after NR is turned off.
- Protect application image reuse across successful native NR captures and rejected submissions.
- Reconcile native frame IDs after capacity waits and order private FG depth with the producer that owns it.
- Keep tracking cache validity consistent and close the startup frame cleanly on worker shutdown.

## Validation

The host passed 23 stereo-delivery cases, 10 NR runtime cases and 43 CPU checks. The automated cases used
isolated Direct3D queues with controlled NR readiness or an inference stand-in. Local headset testing on an
RTX 4090 reported smooth 3× FG with NR active. These checks cover the tested paths and configurations.

## Install or upgrade

1. Download both Windows x64 ZIPs and verify them against `SHA256SUMS-2026.11.18.1.txt`.
2. Close VR games and follow the [quickstart](../NR-FG-QUICKSTART.md). Keep the two runtime DLLs and
   `CUSTOM-RUNTIME.json` together. The **Controls 2026.11.16.1** executable is carried forward.
3. Restart Virtual Desktop Streamer. Reconnect your headset if needed, select **VDXR** in Streamer, and
   keep **SSW Off** for OFXR. Existing NR and FG profiles continue to apply.

The runtime and FG module use the source and license notices in the corresponding-source archive.
The download contains no NVIDIA NR DLL or model. NR requires a separately supplied compatible licensed component.
